Target platforms
----------------
- Linux: native CLI + Qt GUI, preserving the existing Linux dependency/audio/capture flow.
- FreeBSD: native CLI + Qt GUI, preserving existing base-Clang/libc++, BPF/devfs, audio preflight, and guarded HDA handling.
- macOS 13+: native CLI + Qt GUI .app + optional DMG. Builder performs full-Xcode preflight, Homebrew dependency bootstrap, managed PJSIP 2.17, split-Qt/macdeployqt deployment, Cocoa plugin verification, ad-hoc signing, install/uninstall lifecycle.
- Termux/Android: native CLI + Qt GUI build. CLI runs in the terminal; GUI requires Termux:X11. Builder installs the Termux toolchain/Qt dependencies and managed PJSIP 2.17.

Builder entry points
--------------------
./build.sh                         auto-detect current platform
./build.sh --os linux ...          Linux builder
./build.sh --os freebsd ...        FreeBSD builder
./build.sh --os macos ...          macOS builder
./build.sh --os termux ...         Termux/Android builder
