S.I.P.H.E.R. 1.0.0-r18 — Linux CTest release-gate hotfix
========================================================

Problem
-------
The r18 application compiled successfully on Linux, but CTest still registered
historical r15/r17 release gates.  r15-core-preservation correctly detected the
intentional r18 changes to PbxAudit/SipTrace/SipWireMonitor and therefore failed.
The inherited r17 phreak-UI test also incorrectly required the literal r17
version string, so it failed on a correct r18 Version.h.

Fix
---
- CMake/CTest now registers r18-core-preservation instead of the historical
  r15-core-preservation hash gate.
- CTest now registers the r18 DID/route/audit source contract and the
  all-platform builder source contract.
- The inherited r17 phreak-UI test validates the retained S.I.P.H.E.R. display
  identity/edition and UI behavior without pinning the obsolete r17 version.
- Historical r15/r17 scripts remain in the source tree for baseline/reference
  use; they are no longer mistaken for the current r18 CTest release gate.

This hotfix is additive to the prior r18 compile fixes:
- PJSIP 2.17 RX peer metadata compatibility.
- Qt `emit` macro collision in MainWindow::analyzeNextOut().
