S.I.P.H.E.R. 1.0.0-r18 DID/Route Audit — Linux/Qt/PJSIP compile hotfix
=====================================================================

This bundle includes both post-r18 native-build fixes:

1. PJSIP 2.17 receive-peer API compatibility
   - Removed invalid pjsip_rx_data::pkt_info.addr references.
   - Incoming peer telemetry uses pkt_info.src_name and pkt_info.src_port.

2. Qt GUI `emit` macro collision
   - MainWindow::analyzeNextOut() previously declared a local lambda named `emit`.
   - Qt defines `emit` as a macro, causing GCC/Clang to see invalid C++ (`auto = ...`).
   - The helper is now named `appendHeaderList`.
   - The r18 source regression test rejects reintroduction of this identifier collision.

Validation in packaging environment
-----------------------------------
PASS - tests/run_r18_regression.sh
PASS - PJSIP 2.17 source compatibility guard
PASS - Qt `emit` identifier regression guard
PASS - archive integrity

A full Qt native link cannot be performed in the packaging container because Qt 6
development files are not installed there. The reported compile failure is a deterministic
preprocessor collision and is corrected in the source.
