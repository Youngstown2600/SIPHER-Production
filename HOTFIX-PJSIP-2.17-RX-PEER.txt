S.I.P.H.E.R. 1.0.0-r18 DID-Route-Audit — PJSIP 2.17 RX Peer Hotfix
==================================================================
Date: 2026-09-10

Problem fixed
-------------
The r18 SIP receive-wire callback referenced rdata->pkt_info.addr. PJSIP 2.17
exposes the received peer as pkt_info.src_addr / src_name / src_port; there is
no pkt_info.addr member. On Linux this caused SipWireMonitor.cpp to fail at
compile time.

Fix
---
Incoming request/response peer telemetry now reads:
  rdata->pkt_info.src_name
  rdata->pkt_info.src_port

Outbound handoff/next-hop telemetry remains unchanged and uses:
  tdata->tp_info.dst_name
  tdata->tp_info.dst_port

Target-native note
------------------
The packaging environment does not provide a complete native Qt/PJSIP target
stack, so the actual final Linux GUI link should still be run on the target
Linux host. This hotfix directly addresses the PJSIP 2.17 API compile error
reported in SipWireMonitor.cpp.
