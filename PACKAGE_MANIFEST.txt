SIPHER 2.1 — GitHub-ready full source bundle

Public executable
-----------------
- One executable: `sipher`.
- Terminal/TTY launches select the CLI; desktop launches select the GUI.
- `--cli`, `--gui`, and `SIPHER_UI=cli|gui` override automatic selection.

Included 2.1 feature baseline
-----------------------------
- r18 route/audit/security fixes and r19 simultaneous multi-SIP/zero-account startup retained.
- Qt 6 QTableWidget double-click compile fix retained.
- Runtime/config/install namespace is SIPHER-only (`~/.config/sipher`, `~/.local/state/sipher`, `share/sipher`, `share/doc/sipher`).
- DID Intelligence uses a provider waterfall and suppresses full failed-provider sections.
- USACallerLookup remains the no-key US carrier/rate-center/FTC source.
- SkipCalls is the no-key primary US spam reputation source.
- Carrier fallback order when configured: Data247/Carrier247 → Veriphone → Omkar.
- SpamCalls.net → tellows remain best-effort reputation fallbacks.
- Optional enhanced Neutrino HLR/current-carrier lookup remains explicit-only.
- Legacy Blue Box/Red Box panels play local-only non-signaling demo audio.

Build entry point
-----------------
    ./build.sh

Supported targets
-----------------
- Linux
- FreeBSD
- macOS 13+
- Termux/Android
- Windows 10/11 portable

Validation
----------
Run the complete source/regression gate with:

    bash tests/run_2_1_regression.sh

This archive intentionally contains source, build scripts, tests, examples, documentation, and GitHub workflow files, but no local build directory or generated binaries.
